EMERHOP · beta for Android

Messages that hop from phone to phone.

When towers and internet go down, EMERHOP turns nearby phones into a relay chain. Chat, send SOS and keep trying 112, with no network at all.

Press send to watch a message travel A → B → C.

How it works

Multi-hop mesh

If your contact is out of range, your message hops through other EMERHOP phones (Node A → Node B → Node C) until it arrives. Relay phones carry it but can’t read it.

Encrypted by default

Keys are exchanged with ECDH P-256 and messages are sealed with AES-GCM using WebCrypto. When you pair by QR code or IP, both phones show the same 6-digit fingerprint. Compare them to be sure nobody is in the middle.

SOS that keeps trying

SOS broadcasts encrypted beacons across the mesh and keeps redialing helpline 112 in the background, so the call connects the moment a signal appears.

Intel Scanner (maps beta)

Checks crowd surge, weather and TRAI carrier conditions to predict a blackout and suggest switching to the mesh before it happens.

Install EMERHOP

EMERHOP runs on Android. It’s installed from an APK file, so Android will ask for one permission first.

  1. Download the APK

    Open this page on your Android phone and tap the button.

    Download APKAPK link not set yet. Add it in “Upload your app” below.

  2. Allow the install

    Open the downloaded file. When Android asks, allow installs from your browser or file manager. You can turn this off again afterwards.

  3. Grant permissions in order

    Bluetooth first, then contacts, then create your account with your name and phone number.

  4. Pair with a friend

    Scan each other’s QR code, then check that the 6-digit fingerprint matches on both phones.

Upload your app to this page

This page can’t store the APK itself. Put the file on a host that gives you a public link, then connect that link to the Download button.

Option A: Supabase Storage

  1. Open your Supabase dashboard, then Storage.
  2. Create a bucket named releases and mark it Public.
  3. Upload app-debug.apk (or your release APK).
  4. Open the file and copy its public URL.

Option B: GitHub Releases

  1. In your repository, create a new Release with a version tag.
  2. Attach the APK file to it.
  3. Publish, then right-click the APK under Assets and copy the link.

  1. Test your link here

    Paste the link and the Download button above will use it right now.

  2. Make it permanent

    This test lasts only until you reload. To keep it, send the link back to Claude and the page will be republished with it built in. Or set APK_URL in the page’s script.

Before you share it widely. app-debug.apk is a test build. For other people, build a signed release APK, or publish on Google Play, which avoids the “unknown source” prompt.
